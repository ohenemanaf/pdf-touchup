eng.traineddata: English OCR model for Tesseract, from the tesseract-ocr/tessdata project
(https://github.com/tesseract-ocr/tessdata), licensed under the Apache License 2.0
(see LICENSE-Apache-2.0.txt). PyMuPDF's built-in Tesseract engine reads it from here,
so no separate Tesseract install is needed.
